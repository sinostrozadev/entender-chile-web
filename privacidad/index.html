Privacidad

Política de privacidad

Entender Chile es un informe de noticias. Este sitio y el canal de YouTube no piden datos personales ni los guardan.

Este sitio

  • No tiene cuentas, formularios ni registro. No usa cookies propias de seguimiento ni herramientas de publicidad.
  • Está alojado en GitHub Pages; GitHub puede registrar datos técnicos de acceso (como la dirección IP) según su propia política de privacidad.
  • Los videos incrustados provienen de YouTube y quedan sujetos a la política de privacidad de Google al reproducirlos.

Herramientas propias que usan la API de YouTube

Para publicar las ediciones usamos una aplicación propia conectada a los servicios de YouTube (YouTube Data API). Esa aplicación accede únicamente a nuestro propio canal, con el fin de subir los videos, sus descripciones y miniaturas. No accede a información de otros usuarios, no recopila ni almacena datos de terceros y no comparte información con nadie. Al usar los servicios de YouTube, aceptamos los Términos de servicio de YouTube.

Contacto

Para cualquier consulta sobre privacidad, escribe a entenderchile@gmail.com.
